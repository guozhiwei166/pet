## 数据库重建

```sql
mysql -uroot -p < backend/sql/schema.sql
mysql -uroot -p tourism_homestay < backend/sql/data.sql
```
注意:data.sql 会自动为所有房型生成未来 60 天日期库存;订单日期相对"导入当天"动态生成,任何时间导入演示数据都可用。

## 已知说明(非缺陷)

1. 业务冲突类异常(如重复支付/重复评价)返回 code 500 而非 409,提示文案明确,演示无碍;如需可在答辩前统一调整为 409(改 BizException 调用处即可)。
2. 图片使用 picsum.photos 外链,演示需联网;离线可改用后端上传(/api/upload/image,文件存 backend/uploads/,访问 /uploads/**)。
3. 前端 chunk 较大(Element Plus 全量引入),毕设演示无性能问题;如需优化可改按需引入。
4. 待支付订单 15 分钟自动取消由后端定时任务执行(每 5 分钟),演示"取消恢复库存"可优先用前台"取消订单"按钮。
