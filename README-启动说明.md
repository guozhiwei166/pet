# 🐾 猫狗宠物寄养系统 启动说明（自己动手版）

以后不用找 AI，**双击 `start.bat` 就能启动项目**。

---

## 一、日常启动（只需两步）

1. **双击 `start.bat`**
2. 等它自动打开浏览器 → 进入 http://localhost:5190

> 会弹出两个黑色窗口（后端窗口 / 前端窗口），**保持打开别关**，关掉=服务停止。

**演示账号**：
| 角色 | 账号 | 密码 |
|---|---|---|
| 宠物主人 | `user` | `user123` |
| 工作人员 | `staff` | `staff123` |
| 平台管理员 | `admin` | `admin123` |

---

## 二、日常停止

双击 **`stop.bat`** → 按提示输入 `y` 可连 Redis 一起停（输 N 则保留 Redis，下次启动更快）。

---

## 三、常见问题

### Q1：提示"MySQL 未运行"
MySQL 是常驻服务，正常开机自启。若没启动：
- 开始菜单搜索 **Services**（服务）→ 找到 `MySQL80` → 右键"启动"；或
- 运行 `net start MySQL80`（需管理员终端）

### Q2：启动后 8082 起不来 / 窗口报端口占用
多半是上次没停干净。先跑 **`stop.bat`**，再重新双击 `start.bat`。

### Q3：我想把数据恢复成全新演示数据
数据库现在是"持久模式"，不会自动重置。想恢复出厂演示数据：

1. 双击 **`reset-demo.bat`** → 输入 `YES` 回车
2. 等后端窗口出现 `Started PetCareApplication` 后，按 `Ctrl+C` 停掉
3. 双击 `start.bat` 正常启动即可（数据已重置并会一直保留，不再自动重置）

### Q4：工具被我移动位置了
打开 `start.bat`，改文件顶部的 5 个路径变量（REDIS_EXE / NODE_DIR / JAVA_HOME / MAVEN_CMD）。

---

## 四、启动脚本内部做了什么（了解即可）

| 步骤 | 动作 |
|---|---|
| 1 | 检查 MySQL（3306）是否运行 |
| 2 | 若 Redis(6379) 没运行 → 启动它 |
| 3 | 若后端(8082) 没运行 → 新窗口 `mvn spring-boot:run` |
| 4 | 若前端(5190) 没运行 → 新窗口 `npm run dev` |

脚本有"幂等保护"：已经跑着的服务不会重复启动，所以**重复双击 start.bat 也安全**。

> 注：后端窗口启动日志出现 `Started PetCareApplication` 即就绪；若首次使用数据库为空，后端会自动建库建表并写入演示账号（约 30 秒）。
